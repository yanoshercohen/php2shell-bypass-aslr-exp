# English fork maintenance

This fork publishes English documentation. Keep links and attribution to the original Chinese upstream repository at https://github.com/9bie/php2shell-bypass-aslr-exp.

When syncing upstream:
- Preserve the English README and existing English translations.
- Translate newly added Chinese documentation into English.
- Do not add or restore Japanese documentation, Japanese README files (including `readme_ja.md`), or Japanese language-navigation links. This is the owner's explicit standing preference.
- Preserve the original Chinese upstream references; do not replace them with links to the English fork.
- If an upstream merge restores Japanese content, remove it from the resulting tree before publishing the sync.
